# MetaSonGi Motion Portfolio

세 가지 디자인(ORBIT / SIGNAL / ATELIER)을 버튼이나 드래그 슬라이더로 전환하는 정적 포트폴리오입니다.

- Three.js 실시간 3D: 반사·굴절 느낌의 금속 오브젝트, 발광 입자, 궤도, 별 배경
- 메인 장면: 마우스/터치 드래그 회전, 긴 가로 스와이프로 디자인 전환, 방향키 조작, 스페이스/버튼으로 입자 확산
- 스크롤에 따라 하나의 3D 장면이 프로젝트·개발 철학·소개·연결 섹션으로 이어지고, 고정된 중간 장면에서는 타이포와 입자가 함께 변형됩니다.
- 포인터를 따라 기울어지는 프로젝트 카드와 커서 효과, 디자인 전환 와이프, 섹션 진행 내비게이션
- 프로젝트: 가로 드래그, 상세 모달, 실제 GitHub 저장소 연결
- 반응형 화면, 스크롤 등장 효과, 모션 일시정지, reduced-motion 지원
- 소개와 프로젝트 정보는 현재 대화에서 확인한 내용만 사용했습니다. 경력/고객/수상 이력은 가정하지 않았습니다.

`dist/`를 정적 서버로 제공하면 실행됩니다. Three.js는 `dist/vendor/`에 함께 포함되어 외부 CDN 없이 로드됩니다. Three.js의 MIT 라이선스는 `dist/vendor/THREE-LICENSE.txt`에 포함했습니다. Google Fonts를 로드하지 못하면 시스템 글꼴을 사용합니다. WebGL을 지원하지 않는 환경에서도 프로젝트 정보와 탐색은 사용할 수 있습니다.
